# FootyMadness — Design Context (.better-web-ui.md)

## Target audience
- Primary: FM / FIFA / PES brains 16–40, desktop for dense tables + phone on matchday. Data-literate, tolerate density.
- Secondary: casuals checking one tie before kickoff.
- Context: dugout desk + phone in stand. Fast scan, then drill down.

## Jobs to be done
1. Compare refs by pens/cards/home-away splits vs league avg, with why it matters.
2. Grade tactical breakdowns (originality/insight/clarity) and surface payouts.
3. Scan fan mood (public only) as dB, not a trade signal.
4. Spot style mismatches (press vs build-up, set-pieces) with corners/cards volume reads.
5. Build and share fan XIs (creator) as images.

## Brand personality / tone — FM-dugout × FUT (not VaunMusic copy)
- Dugout Authority: dense, tabular, chalkboard-calm. Small caps labels, tabular numerals, pitch-green tinted neutrals.
- FUT Snap: gold `#E8C547` reserved for ratings/pouches/clash % only. One gold moment per view, rest quiet.
- Voice: coach-clipboard short. No hype-beast, no corporate SaaS, no profit promises.
- Visual: deep pitch `#0A120B`, card `#121A12`, edge `#263026`, chalk `#EDF2E6`. Display Anton uppercase, body Space Grotesk. No gradients-everywhere, no glassmorphism, no emoji-as-UI.
- Data-viz: bars start at zero, direct labels, text insight before chart. No red-green-only coding.

## Stack (match first)
- Next.js 16 App Router, React 19, Tailwind v4 (`@import "tailwindcss"`, `@theme` tokens), no component library.
- Icons/crests/pitches: inline SVG/CSS only (offline-safe). Motion: CSS transform/opacity, ease-out-quart, stagger 60–70ms, `prefers-reduced-motion` guard.
- Tables: right-aligned numerals, sticky headers desktop, rows over cards. 44px targets, gold focus ring.

## What NOT to do
- Do not reuse VaunMusic volt/ember as primary. Do not copy music rails/cover grids.
- Do not add betting, odds, escrow, P2P pools, private scraping, or win-probability language.
- Do not fetch external images; crests/pitches stay inline.
